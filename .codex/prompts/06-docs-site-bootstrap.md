# Arkivra Docs Site Bootstrap

Assume the role of `arkivra-docs-writer`, with architecture review when choosing structure.

## Goal

Plan or implement the initial Arkivra documentation structure and first drafts for self-hosting, configuration, security/privacy model, vaults, search, optional AI, and operations.

## Inspect

- Root `AGENTS.md` and `docs/AGENTS.md`.
- README, `.env.example`, `docker-compose.yml`, package scripts, and relevant source behavior.
- Existing `docs` files.
- Marketing website copy for consistency.

## Do Not Change

- Do not introduce a docs framework or build tooling unless explicitly requested.
- Do not invent behavior or configuration options.
- Do not overclaim privacy, encryption, AI, or security.

## Requirements

- Prioritize a content plan first unless implementation is explicitly requested.
- Use concrete file references.
- Make caveats for cloud/remote AI providers explicit.
- Keep self-hosting and non-AI document workflows prominent.
- Include commands that match the repo.

## Final Output

- Summary
- Changes made
- Tests/checks run
- Risks
- Follow-up tasks
