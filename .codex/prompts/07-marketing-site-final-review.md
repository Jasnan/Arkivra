# Arkivra Marketing Site Final Review

Assume the role of `arkivra-frontend-ux-reviewer` and `arkivra-docs-writer`.

## Goal

Review `apps/website` for public-release polish, copy accuracy, positioning consistency, accessibility, responsiveness, and build readiness.

## Inspect

- `apps/website/src/pages`, `src/components`, `src/content`, localization files, styles, and config.
- README and docs references for consistency.
- Product behavior related to AI, search, storage, encryption, and self-hosting.

## Do Not Change

- Do not change product positioning without explicit implementation approval.
- Do not add unsupported claims like fully private, zero-knowledge, or end-to-end encrypted.
- Do not create a broad redesign unless requested.

## Requirements

- Prioritize a report first unless implementation is explicitly requested.
- Use concrete file references.
- Check first-viewport clarity, localization consistency, CTA accuracy, and release credibility.
- Run `pnpm --filter @arkivra/website check` and build when implementing changes.

## Final Output

- Summary
- Changes made
- Tests/checks run
- Risks
- Follow-up tasks
