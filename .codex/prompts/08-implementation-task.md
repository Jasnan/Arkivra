# Arkivra Implementation Task

Assume the role of `arkivra-implementer`.

## Goal

Implement the requested scoped change in Arkivra using existing repo patterns.

## Inspect

- Root `AGENTS.md` and nearest app-specific `AGENTS.md`.
- Relevant source files and tests.
- Package scripts for the affected app.
- Docs/copy when behavior or claims change.

## Do Not Change

- Do not make unrelated refactors.
- Do not change app behavior outside the requested scope.
- Do not weaken auth, RBAC, encryption, storage, parser, backup, or AI data boundaries.
- Do not make unsupported privacy/security claims.

## Requirements

- Make the smallest useful change.
- Add or update tests when behavior changes.
- Run targeted checks first, then broader checks when risk warrants.
- Use concrete final file references.
- Preserve self-hosted-first and optional-AI positioning.

## Final Output

- Summary
- Changes made
- Tests/checks run
- Risks
- Follow-up tasks
