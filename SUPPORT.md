# Getting help with Arkivra

Choose the channel that best matches what you need:

- Read the [documentation](https://docs.arkivra.app) for installation, configuration, document processing, backups, and troubleshooting.
- Use [GitHub Discussions](https://github.com/Jasnan/Arkivra/discussions) for deployment questions, usage help, early ideas, and general feedback.
- Open a [bug report](https://github.com/Jasnan/Arkivra/issues/new/choose) for a reproducible problem in Arkivra.
- Follow [SECURITY.md](SECURITY.md) for suspected vulnerabilities. Never report them in a public issue or discussion.

Arkivra is an open-source project maintained on a best-effort basis. Community support does not include guaranteed response times. When asking for help, include the Arkivra version, deployment method, relevant configuration with secrets removed, and concise reproduction steps.

Do not post credentials, access tokens, encryption keys, private documents, extracted text, database contents, or unredacted provider payloads.
