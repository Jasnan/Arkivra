# Arkivra Docs Agent Guide

Follow the root `AGENTS.md` first. Applies to `apps/docs`.

## Rules

- Public Arkivra docs built with Starlight.
- Keep setup, config, migrations, backups, restore, search, and AI provider docs aligned with code.
- Prefer practical self-hosting and operations language.
- State AI as optional and provider-configured.
- Avoid privacy, security, AI, and encryption overclaims.
- Explain remote/cloud provider data exposure clearly.
