# Arkivra Website

This is the Astro marketing website for Arkivra, an open-source document system for organizing files into vaults, searching across them, and chatting with documents using local or cloud AI models.

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm preview
```
